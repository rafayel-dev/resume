# Rafiul Islam — Portfolio

Personal portfolio of Rafiul Islam, Fullstack & React Native Developer.

**Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4

## Pages

- `/` — About, services and tech stack
- `/resume` — Education, experience and skills
- `/works` — Projects, filterable by category
- `/contact` — Contact details and a message form (Formspree)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
