# Developer Portfolios Monorepo 🚀

This repository houses 3 distinct modern portfolio projects in separate workspaces:

```
├── current-portfolio/     # Rafiul Islam's Personal Portfolio (Next.js 16 + React 19 + Tailwind CSS v4)
├── space-portfolio/       # Space & Galaxy 3D WebGL Portfolio (Next.js 14 + Three.js + Framer Motion)
└── keyboard-portfolio/    # Interactive 3D Mechanical Keyboard Portfolio (Next.js + React Three Fiber)
```

---

## 📁 1. Current Portfolio (`current-portfolio`)
The production-ready executive developer portfolio for **Rafiul Islam** (Executive Frontend & Mobile Engineer / Fullstack Developer).

* **Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4.
* **Features:** 11 Real-world projects showcase, CV download, Formspree contact form, Dark/Light mode sync.
* **How to run:**
  ```bash
  cd current-portfolio
  npm install
  npm run dev
  ```
  Open [http://localhost:3000](http://localhost:3000).

---

## 🌌 2. Space 3D Portfolio (`space-portfolio`)
A stunning cosmic and galaxy-themed 3D portfolio based on [Sanidhyy's space-portfolio](https://github.com/sanidhyy/space-portfolio).

* **Tech Stack:** Next.js 14, Three.js, React Three Fiber, Framer Motion, Tailwind CSS, TypeScript.
* **Features:** Animated starfield & galaxy WebGL canvas, cosmic black hole effect, encrypted skill cards, smooth page motion.
* **How to run:**
  ```bash
  cd space-portfolio
  npm install
  npm run dev
  ```
  Open [http://localhost:3000](http://localhost:3000).

---

## ⌨️ 3. 3D Mechanical Keyboard Portfolio (`keyboard-portfolio`)
An award-worthy interactive 3D portfolio featuring a fully modeled mechanical keyboard based on [Txema Albero's 3d-portfolio](https://github.com/Txemalon/3d-portfolio).

* **Tech Stack:** Next.js, React Three Fiber (R3F), Three.js, Tailwind CSS, Web Audio API.
* **Features:** Interactive 3D mechanical keyboard that tilts with cursor movement and plays mechanical switch sound clicks on key presses, project modals, bilingual options.
* **How to run:**
  ```bash
  cd keyboard-portfolio
  npm install
  npm run dev
  ```
  Open [http://localhost:3000](http://localhost:3000).
